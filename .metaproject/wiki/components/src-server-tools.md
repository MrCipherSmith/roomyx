## Overview

The `src/server/tools` module implements the four MCP tools that the roomyx server exposes to clients: `room.get_state` (roster and goal), `room.get_transcript` (messages), `room.get_agent_delta` (unseen messages for an agent), and `room.get_agent_detail` (all messages from an agent). Each tool is read-only, loads the room log on demand, and applies filtering or aggregation to answer the query. Together, they provide full visibility into a room's content.

## How it works

Four independent tools, each following the same pattern: load the room log via `loadRoomLog` from src/log, apply filtering or aggregation, and return structured data. **get-transcript.ts** returns a page of messages after a cursor, with a limit and a has_more flag to prevent silent truncation. **get-agent-delta.ts** returns unseen messages for an agent since a given seq or cursor, computing the unseen set via `getAgentDelta`. **get-agent-detail.ts** returns all messages from a specific agent and the last seq they reached, via `getAgentDetail`. **get-state.ts** returns the current roster, goal contract, log path, and dispatcher status. All tools use Zod schemas for output validation before returning.

## Key concepts

**TranscriptPage** — Messages, a has_more flag, and next_seq cursor to prevent truncation ambiguity. **DEFAULT_TRANSCRIPT_LIMIT** (200) — Default message limit to avoid shipping entire rooms as one response. **Agent delta** — Messages an agent has not seen since a reference point (their last message or a caller's cursor). **Agent detail** — All messages from an agent and the seq they last reached. **Read-only** — No tool writes to the log; all modifications go through `room.post_owner_command`.

## Main flows

**Get transcript**: Caller provides since_seq and optional limit; tool loads log, extracts messages after that seq, slices to limit, and returns the page with has_more and next_seq. **Get agent delta**: Caller provides agent ID and optional since_seq; tool computes which messages the agent has not seen (after their own messages or after the cursor), and returns them. **Get agent detail**: Caller provides agent ID; tool loads all messages, filters by agent, and returns the list plus lastSeenSeq. **Get state**: Tool loads log, computes current state via foldEdits, and returns roster, goal, log_path (optional), and dispatcherAttached (boolean).
