## Overview

The `test/installer` module contains tests for room registry, history, project initialization, and skill synchronization. Tests exercise registry locking, room registration/deregistration, history indexing, and skill bundle installation under various conditions.

## How it works

Tests verify: registry operations under concurrent access (lockfile behavior), room registration with atomicity, deregistration with history archival, history file format and corruption handling, project initialization scaffolding, and skill file installation. Tests use temporary directories and files cleaned up after each test, and check file state and exceptions to validate behavior.

## Key concepts

**Registry consistency** — Atomicity under write-then-rename. **History indexing** — Append-only log of closed rooms. **Skill installation** — Copying bundled skill files to project directories.

## Main flows

**Register room**: Create registry entry, write with lock, verify entry appears. **Concurrent access**: Multiple processes attempt registry read/write, verify no corruption. **Close room**: Deregister room, verify history entry appended and registry entry removed. **Initialize project**: Call init(), verify directories created and optional skill installed.
