## Overview

The `src/client/components` module provides reusable UI components for the TUI, including the status bar, message row renderer, roster sidebar, help overlay, and footer. These components handle display formatting, rendering helpers, and UI composition, abstracting away text layout and key binding documentation from the main viewer.

## How it works

Five independent components, each using @opentui/core's text rendering and table primitives: **status-bar.ts** renders a one-line display of room state (status, goal progress); **message-row.ts** formats a single message for display (from, body, timestamp); **roster-sidebar.ts** renders the agent list with selection highlight; **help-overlay.ts** displays key bindings and usage instructions via `bindingRows` and `helpBody`; **footer.ts** shows pagination or other status. Each component is a pure function or has minimal state, called by the viewer to render or update the screen.

## Key concepts

**DisplayStatus** — The connection status displayed (connecting, connected, disconnected). **StatusBar** — Single-line summary at the top. **HELP_WIDTH** — Maximum column width for help text (e.g., 80). **bindingRows** — Array of key-binding documentation (key, description). **helpBody** — Formatted help text. **HelpOverlay** — Modal component that shows help.

## Main flows

**Render status bar**: Viewer calls `StatusBar` with current state (goal, progress, agent count), gets formatted text. **Render message**: Viewer calls `messageRow` with a MessageEnvelope, gets formatted line(s) with sender, timestamp, body. **Render roster**: Viewer calls `RosterSidebar` with agents and current selection, gets table-formatted output. **Show help**: Viewer calls `HelpOverlay` with keybindings, gets modal text. **Render footer**: Viewer calls `Footer` with current position, gets pagination line.
